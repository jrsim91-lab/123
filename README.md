# QMS Change Manager — GitHub Pages Prototype

의료기기 QMS 변경관리 업무를 위한 웹 화면 시제품입니다.

## 포함 기능
- 대시보드 및 변경 현황
- 변경 신청 등록 및 자동 변경번호 발급
- 변경 목록 검색 및 상태 필터
- 영향평가 항목 등록
- 검토자/승인자 정보 기록
- 실행 항목 및 완료 체크
- 검증 결과 기록 및 단계 진행
- 종료 상태 관리
- 변경관리대장 CSV, 통계 CSV, JSON 백업 다운로드

## GitHub Pages에 게시하기

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `index.html`, `style.css`, `app.js`, `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. Build and deployment에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 Save를 누릅니다.
6. 잠시 후 표시되는 GitHub Pages 주소로 접속합니다.

## 로컬에서 실행하기
세 파일을 같은 폴더에 두고 `index.html`을 브라우저에서 열면 됩니다.

## 중요: 시제품의 한계
이 버전은 브라우저 `localStorage`에 데이터를 저장합니다. 따라서 브라우저/기기별로 데이터가 분리되고, 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. 인증, 서버 DB, 파일 첨부 보안, 사용자별 권한, 변경 전후 감사추적, 서버 백업/복구가 구현되어 있지 않습니다.

**실제 ISO 13485 품질기록 운영에 사용하지 마세요.** 실제 운영 전에는 사내 서버의 FastAPI + PostgreSQL 백엔드, 접근통제, 서버 측 상태전환 검증, 감사추적, 파일 무결성, 백업/복구, 소프트웨어 검증을 구현하고 승인해야 합니다.
